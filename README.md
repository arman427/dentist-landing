# Стоматология «Бриз»

Демонстрационный pet-проект лендинга стоматологической клиники на Next.js.

## Запуск локально

```bash
bun install
bun dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверка перед деплоем

```bash
bun run lint
bun run build
```

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel.
2. Оставьте framework preset `Next.js` и стандартную команду сборки.
3. Добавьте переменную `NEXT_PUBLIC_SITE_URL` с адресом production-деплоя.
4. Запустите деплой.

После публикации Next.js автоматически отдаёт:

- `/sitemap.xml` — карту публичных страниц;
- `/robots.txt` — правила индексации.

Запись на консультацию в этом demo-проекте не отправляется в клинику.
